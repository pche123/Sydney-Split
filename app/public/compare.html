Which cities can be compared?

Planners often want to model one city on another. That only works if the same thing was measured the same way in both. This page shows which lines each city has, where the definitions differ, and what other countries' data could support.

Same name, different measure

A "Degree Line" exists in all three countries, but each census asks a different question. Within a country, cities compare like with like; across countries, compare the shape and the verdict, not the numbers.

Five rules for comparing cities

  1. Same line, same definition. Compare two cities on a line only if both have it (a mark above) and the definition table says it was measured the same way.
  2. Compare verdicts and shapes, not percentages. "Real line in both" or "inner-city core in both" travels; "34% vs 41% degree holders" does not, across countries.
  3. Area size matters. Smaller areas show sharper edges and give the tests more to work with. Adelaide (86 areas) can only confirm very sharp lines; London (1,002) can confirm subtle ones.
  4. Census dates matter. Japan counted in 2020, Australia and England in 2021, partly under COVID rules. Commuting and working from home are the most affected.
  5. Restaurant and shop data come from different sources (licences, hygiene records, HotPepper, OpenStreetMap). Treat venue lines as comparable in shape only.
