# Experiments

Studies behind `FINDINGS.md` and the paper. `audit/` holds the full audit (calibration, power, final verdicts); the top-level scripts are the earlier sharpness experiments. Scripts read the pipeline's working folders from `SPLIT_SYDNEY_WORK`, `SPLIT_TOKYO_WORK` and `SPLIT_RAW` (see `paths.py`). The README's results table says which script makes which result.
